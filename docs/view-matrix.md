# Design view coverage matrix

Source: [renderable canvas](../design/all_design_files/AAC%20Unified%20Site.dc.html) and [single-file export](../design/design_one_file.html). Both render the same 60 panel IDs and identical panel text. Roles: P = public, M = signed-in member, O = officer (officers also have normal member views). Feature IDs refer to [the implementation plan](implementation-plan.md#feature-list).

Each row is required; a panel containing several states needs one test fixture per state. All applicable rows must be exercised at phone, tablet, and desktop sizes, not only the dimensions drawn. Dialogs and phone frames are not independent routes. Query `tab` values are canonical and persist on refresh; omitted tab defaults to signups when enabled, otherwise recap. The quarter picker is shown in the member context as needed and in officer tools; event routes derive their quarter from the occurrence.

The latest combined Home/About (5a/5b) replaces older Home/About iterations referenced in `github.md`. IDs 1a, 1c, 4a, 3l and 6d are not present; do not invent pages for them. Sponsors belongs to the old website and has no new design; it is outside this build. Public `/about`, old aliases, and the old reimbursement page are not compatibility obligations.
